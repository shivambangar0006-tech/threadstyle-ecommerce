# ThreadStyle — Week 2 Front-End Prototype

This is the Week 2 front-end and UX prototype for ThreadStyle – Apparel & Fashion E-Commerce Website.

## Included
- Responsive home page and navigation
- Apparel categories
- Product catalogue
- Product details
- Search, filtering and sorting
- Size, colour and availability information
- Shopping bag/cart interface
- Mobile/tablet/desktop responsive layout

## Scope
Week 2 is intentionally front-end focused. Backend, APIs, database/inventory integration and checkout/order processing are planned for later internship weeks.
